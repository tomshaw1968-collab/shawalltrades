This is a sample project folder so you can see how the gallery looks
with content in it. Delete this whole "example-project" folder once
you've got real project photos to upload — this README and the two
sample images will not show up in "Our Projects" once removed.

To add a real project:
1. Create a new folder inside /projects named after the job,
   e.g. "kinross-avenue-reroof" or "Smith Kitchen Extension".
2. Drop the photos and/or videos for that job straight into the folder
   (no need for sub-folders inside it).
3. Upload/commit it to GitHub. The gallery rebuilds itself within a
   minute or two — no other steps needed.
